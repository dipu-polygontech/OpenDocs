# FINDINGS-OPENREADER-P6: Full-Codebase Audit Register

## Provenance
Produced 2026-09-19 by four parallel read-only audit passes (readers; core data layer; core presentation/services; feature screens), run after Phase 5 hardening (`FEATURE-OPENREADER-P5`) closed. Each pass read every file in its scope in full (not grep-only), cross-referenced `agentic/data/project-context/features/OpenReader_BRD_v1.0.md`, and was instructed not to re-flag anything the just-landed ODF-P5-08 accessibility pass already covered. Two passes (core data layer, feature screens) independently converged on the same root cause for ODF-P6-01 — treated below as one finding, not two.

This document is the raw register. `agentic/data/work-items/FEATURE-OPENREADER-P6.md` is the work item that plans remediation against it.

## Severity legend
- **CRITICAL** — data loss, crash risk, or OOM risk reachable in ordinary use.
- **HIGH** — real bug or silently-unmet BRD requirement with user-visible impact, not yet crash/data-loss level.
- **GAP** — BRD-required behavior missing or incomplete, no crash/correctness bug.
- **UX** — usability/consistency issue, no correctness bug.
- **CLEANUP** — dead/unreferenced code, no runtime impact today but a risk if reintroduced (see ODF-P6-38 precedent).

## Test coverage gaps (rollup, not individually IDed)
- No test for `DocumentRepositoryImpl.rescan()`'s "delete where path NOT IN found" behavior against a document indexed outside the scanner's roots — the exact scenario behind ODF-P6-01. Highest-value single test to add.
- `AppSettingsRepositoryImpl`, `PreferenceCache`/`SharedPreference`/`base_cache.dart`, `StorageAccessService` (incl. `isPermanentlyDenied()`): zero tests.
- Favorites, Recents, Search screens: zero widget/controller tests (only Home/Files covered in `document_views_test.dart`).
- `ThemeController`, `LocaleController`, `AppShellController`/`AppShellBinding`, every `lib/core/presentation/hooks/use_*.dart`, `PermissionService`, `BaseController`: zero tests.
- No binding/routing tests (`AppPages`/`AppRoutes` wiring) — would have caught both already-fixed `Get.lazyPut`-vs-`Get.put` and `fenix`-vs-`permanent` lifecycle bugs sooner than a real-device manual pass did.
- `test/widgets/document_views_test.dart`'s search test never simulates rapid sequential keystrokes — the ODF-P6-05 race has no regression guard.
- `test/widgets/document_list_tile_test.dart` never asserts on `isFavorite` visual state — ODF-P6-19 has no test that could have caught it.
- Stale test comment in `test/controllers/csv_reader_controller_test.dart:71-73` claims CSV parsing runs on a background Isolate — contradicts the controller's own doc comment (parsing was moved to the calling isolate in TASK-014). Fix the comment regardless of what else happens with ODF-P6-16.
- `IncomingIntentService.init()`/`handle()` are explicitly documented as untestable in this environment (a real, acknowledged tooling limitation — `sqflite` + `Directory.systemTemp.createTemp()` hangs `flutter_test` teardown), not an oversight.
